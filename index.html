O que é

Ajuda de quem não tem nada a ganhar com você

O que move este projeto é o amor e o cuidado com quem precisa. São ferramentas e serviços para essas pessoas, sem segunda intenção: ninguém paga para aparecer aqui, e nada do que está aqui é isca para outra coisa.

Quase toda ajuda que se encontra na internet vem junto com um interesse: um link pago, um cadastro que vira lista de vendas, um “parceiro em destaque” que pagou para aparecer primeiro. Quem mais precisa de informação confiável é justamente quem tem menos como conferir de onde ela veio.

Para ajudar alguém que não conhece você, é preciso primeiro merecer confiança. É a única coisa que este projeto tem para oferecer no lugar de dinheiro — e as regras abaixo são o que essa confiança custa.

Não é uma coisa só. São várias, feitas uma de cada vez, devagar, cada uma pequena o bastante para continuar funcionando depois de pronta.

Os compromissos

As sete regras de neutralidade

Neutro aqui quer dizer uma coisa só: este projeto não tem nada a ganhar com o que recomenda. As regras valem para tudo que ele fizer, sem exceção, e estão aqui para que qualquer pessoa possa cobrar quando forem quebradas.

  1. 01

    O projeto não ganha dinheiro com nada disso

    Sem comissão, sem link pago, sem “parceiro em destaque”, sem vender dado de ninguém — nem com nome, nem sem nome, nem em bolo com os de outras pessoas.

  2. 02

    Pedimos o mínimo de informação

    O normal é não pedir nada. Quando algum dado for mesmo necessário para o serviço funcionar, a própria tela diz qual é, para quê e por quanto tempo fica guardado — antes de você digitar.

  3. 03

    Código aberto nas ferramentas públicas

    “Não guardamos seus dados” é só uma promessa. Com o código aberto, quem entende do assunto pode conferir se é verdade, por conta própria, sem pedir licença.

  4. 04

    Mandamos você para o lugar certo

    Mesmo quando isso significa mandar você embora daqui. Procon, CRAS, Defensoria Pública e SUS não têm substituto, e este projeto nunca se apresenta como alternativa a eles. Quem procura esses canais não está pedindo favor: está buscando o que já é seu por direito.

  5. 05

    Dizemos quando a informação foi conferida

    Tudo que muda com o tempo — uma regra, um valor, um telefone, um endereço — mostra a data em que foi conferido pela última vez. Inclusive esta página.

  6. 06

    Nada é pedido em troca

    Nem religião, nem voto, nem promessa de mudar de vida. Quem é atendido não fica devendo nada a ninguém depois.

  7. 07

    Ninguém é mostrado no pior dia da sua vida

    A necessidade é contada; a pessoa é preservada. Sem foto de sofrimento, sem história montada para comover. Quem foi ajudado uma vez continua tendo futuro — não vira exemplo.

Como uma oferta comercial é avaliada

“Se a gente aceitar, alguma pessoa de bom senso poderia desconfiar que a indicação foi comprada?” Se a resposta for sim, a oferta é recusada — mesmo que a desconfiança seja injusta.

O que a neutralidade custa

Um projeto assim não se paga sozinho: vive de doação e do bolso de quem o mantém. Não tem parceria comercial, não cresce brigando na internet e não junta dados de ninguém para se melhorar. Cresce no boca a boca, que é lento. Nada disso é descuido — é o preço da regra 01, e ele é pago de propósito.

De onde vem

A motivação é cristã. A ajuda não é condicionada

Os valores cristãos explicam por que este projeto existe. Eles nunca são condição para ser atendido por ele.

O nome responde a uma pergunta antiga: quem é o meu próximo? Na história que a responde, quem parou para socorrer o homem caído na estrada foi um estrangeiro, de outra religião. Os que passaram direto eram os homens religiosos. A própria história é uma crítica a quem só ajuda quem é do mesmo grupo.

Daí uma regra prática: nenhuma página de atendimento, material ou conversa deste projeto traz versículo, oração ou símbolo religioso. Para quem está sendo ajudado, símbolo religioso na hora da ajuda soa como preço. Contamos isso aqui, para quem tiver curiosidade. Na hora de ajudar, não se fala disso.

Ninguém é perguntado sobre religião. Ninguém precisa ter nenhuma. O projeto trabalha com paróquias, pastorais e ONGs porque é onde já existe gente organizada e presente nos bairros — e trabalhará com qualquer instituição séria que aceite as sete regras.

O ritmo

Devagar, e para durar

A primeira ferramenta já está no ar. Daqui para a frente, o projeto cresce em dois ritmos diferentes — e isso é de propósito.

As ferramentas pequenas, feitas só de programação — uma conta que se faz sozinha, um guia de passo a passo, um jeito de conferir uma informação — essas podem ser muitas. São baratas de manter, o código é aberto, e existe gente que sabe fazer e se dispõe a ajudar. Quanto mais gente chega, mais elas aparecem.

Os projetos maiores, os que precisam de gente na rua — visitar, conferir, acompanhar uma família ao longo do tempo — esses serão construídos no máximo um por ano. Não é falta de vontade. É que serviço com gente dentro só presta se for feito bem, e fazer bem leva tempo.

Este projeto não está tentando ficar grande. Está tentando durar e fazer diferença de verdade na vida de quem for atendido. Uma coisa bem feita vale mais do que dez pela metade.

Cada coisa nova nasce sabendo quanto trabalho vai dar para manter. E tirar do ar o que não se consegue manter faz parte do plano — é mais honesto do que deixar apodrecer.
